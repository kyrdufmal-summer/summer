## 확인 질문

1. `PRIMARY KEY`는 왜 필요한가요?
   - 각 행을 중복 없이 구분하기 위해 필요합니다.

2. `WHERE` 없이 `UPDATE` 또는 `DELETE`를 실행하면 어떤 문제가 발생할 수 있나요?
   - 조건 없이 실행하면 테이블의 모든 행이 수정되거나 삭제될 수 있습니다.

3. `SELECT *`와 필요한 컬럼만 선택하는 SQL의 차이는 무엇인가요?
   - `SELECT *`는 모든 컬럼을 조회하고, 필요한 컬럼만 선택하면 필요한 데이터만 조회할 수 있어 결과가 더 간단하고 효율적입니다.

4. `COUNT()`와 `AVG()`는 각각 어떤 값을 계산하나요?
   - `COUNT()`는 행의 개수를 세고, `AVG()`는 숫자 컬럼의 평균값을 계산합니다.

5. Python에서 데이터를 처리하는 것과 DB에서 SQL로 데이터를 조회하는 것의 차이를 어떻게 이해했나요?
   - Python은 가져온 데이터를 프로그램 안에서 가공하는 데 적합하고, SQL은 데이터베이스에서 필요한 데이터를 조건에 맞게 조회하고 변경하는 데 적합하다고 이해했습니다.
