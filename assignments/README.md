# Assignments

수업 과제를 과목별로 관리하는 폴더입니다.

## 폴더 구조

```text
assignments/
├─ python/      # Python 과제
└─ database/    # Database / SQL 과제
```

## 기본 규칙

- Python 과제: `assignments/python/`
- Database 과제: `assignments/database/`
- 챕터별 과제는 각 과목 폴더 아래 `ch_01`, `ch_02` 형태로 분리
- API Key, Token, Password, `.env` 등 민감정보는 커밋하지 않음
