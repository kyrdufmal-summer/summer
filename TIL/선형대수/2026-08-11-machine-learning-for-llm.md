# 2026-08-11 | 머신러닝 for LLM — 문제 유형·데이터 분리·평가지표 리마인드

## 1. 오늘의 핵심 질문
머신러닝은 결국 무엇을 하는가?

> 데이터를 넣었을 때 원하는 결과를 얼마나 잘 만들어내는지 학습하는 과정이다.

- 데이터 = 공부할 문제
- 모델 = 문제를 푸는 방법
- 학습 = 데이터를 통해 문제 푸는 방법을 찾아가는 과정

---

## 2. 머신러닝의 기본 구조

### 입력 X와 정답 y

예를 들어 집값을 예측한다면:

```text
X = [집 크기, 역과의 거리, 방 개수]
y = 집값
```

- X = 입력변수, Feature, 독립변수
- y = 출력변수, Target, Label, 종속변수

즉 머신러닝의 가장 기본 구조는:

```text
X를 보고 y를 예측한다.
```

모델은 입력을 받아 결과를 만드는 규칙이다.

예를 들어 아주 단순하게:

```text
집값 = 집 크기 × 1,000만원
```

이라면 84㎡ 집의 예측값은 8억 4천만원이 된다.

실제 머신러닝에서는 사람이 규칙을 직접 정하기보다, 데이터를 이용해 모델이 적절한 규칙을 학습한다.

---

## 3. 선형회귀의 w와 b

선형회귀의 기본식:

```text
y_hat = wX + b
```

- `w` = Weight, 가중치 → 기울기 역할
- `b` = Bias, 편향 → 절편 역할
- `y_hat` = 모델이 예측한 값

쉽게 생각하면:

- 기울기 = 얼마나 기울어졌는가
- 절편 = 어디서 시작하는가
- w = 직선의 방향과 증가 정도
- b = 직선을 위/아래로 이동시키는 값

## 4. 지도학습과 비지도학습

머신러닝은 정답의 존재 여부에 따라 크게 나눌 수 있다.

```text
머신러닝
│
├─ 지도학습: 정답 있음
│  ├─ 분류 Classification → 범주 예측
│  └─ 회귀 Regression → 숫자 예측
│
└─ 비지도학습: 정답 없음
   ├─ 군집화 Clustering → 비슷한 것끼리 묶기
   └─ 차원축소 → 많은 특성을 적은 차원으로 줄이기
```

### 지도학습

정답을 모델에게 알려주면서 학습한다.

#### 회귀 Regression
숫자를 예측한다.

예:
- 집값
- 근속연수에 따른 임금
- 사용 기간에 따른 스마트폰 가격
- 공부시간에 따른 시험점수

핵심 질문:

> 얼마나?

#### 분류 Classification
정해진 범주를 예측한다.

예:
- 스팸 / 정상 메일
- 합격 / 불합격
- 악성 / 양성 종양
- 재활용 품목 분류

핵심 질문:

> 무엇인가?

### 비지도학습

정답을 미리 알려주지 않고 데이터의 구조나 패턴을 찾는다.

#### K-means

```text
"비슷한 데이터끼리 묶어라."
```

예를 들어 고객 데이터를 보고 모델이 다음처럼 묶을 수 있다.

- 그룹 A: 고소득 + 구매 많음
- 그룹 B: 저소득 + 구매 적음
- 그룹 C: 고소득 + 구매 적음

중요한 점은 사람이 처음부터 A/B/C 정답을 주지 않았다는 것이다.

#### PCA

```text
"변수가 너무 많으니 중요한 방향으로 줄여라."
```

고객 한 명에게 나이, 성별, 소득, 구매횟수, 평균구매금액, 방문횟수, 체류시간 등 특성이 100개 있다면 분석과 시각화가 어려워진다.

PCA는 중요한 정보를 최대한 유지하면서 차원을 2~3개처럼 더 작은 수로 줄이는 대표적인 방법이다.

K-means와 PCA는 둘 다 비지도학습이지만 해결하는 문제는 다르다.

---

## 5. 머신러닝의 핵심 학습 루프

```text
데이터
↓
X를 모델에 입력
↓
예측값 생성
↓
실제 정답과 비교
↓
Loss 계산
↓
파라미터 수정
↓
다시 예측
↓
Loss 감소
↓
반복
```

Loss는 예측값과 실제값이 얼마나 다른지를 나타낸다.

> Loss가 작을수록 모델의 예측이 실제 정답에 더 가깝다.

Optimization은 이 Loss를 줄이도록 파라미터를 조정하는 과정이다.

---

## 6. 데이터 분리와 데이터 누수

모델을 제대로 평가하려면 데이터를 나눠야 한다.

- Train = 공부
- Validation = 모의고사 / 모델 선택
- Test = 최종시험

### 데이터 누수의 위험

예를 들어 한 고객이 여러 주문 행을 가지고 있을 때:

```text
고객 A 주문1 → Train
고객 A 주문2 → Validation
```

처럼 같은 고객의 정보가 서로 다른 데이터셋에 섞일 수 있다.

이 경우 Validation에서 처음 보는 고객을 평가하는 것이 아니라, 이미 Train에서 본 고객의 패턴을 다시 보게 될 수 있다.

따라서 데이터 분리 전에 다음을 명확하게 해야 한다.

1. 언제 예측하는가?
2. 같은 개체를 어떤 단위로 묶을 것인가?
3. Train / Validation / Test를 어떤 단위로 나눌 것인가?

핵심:

> 예측 시점과 Split 단위를 명확하게 정해야 데이터 누수를 줄일 수 있다.

## 7. KNN

KNN = K-Nearest Neighbors

```text
"새로 온 데이터가 누구와 가장 비슷한지 보고,
주변 K개의 이웃이 많은 쪽으로 판단한다."
```

즉 새로운 데이터의 가까운 이웃들을 기준으로 예측하는 방법이다.

---

## 8. 선형회귀와 회귀 평가

선형회귀를 만들었다면 다음 질문이 이어진다.

```text
숫자를 예측하는 모델을 만들었다.
↓
그 모델이 얼마나 잘 맞혔는지 어떻게 평가할까?
```

그래서 선형회귀 다음에는 회귀 평가 지표가 필요하다.

## 9. 용어 정리

| 용어 | 이해 방식 |
|---|---|
| Feature | 입력 정보 X |
| Target | 맞혀야 할 정답 y |
| Model | 입력 → 예측을 만드는 규칙 |
| Parameter | 모델 내부에서 학습되는 값 |
| Training | 파라미터를 조정하는 과정 |
| Loss | 얼마나 틀렸는지 |
| Optimization | Loss를 줄이는 과정 |
| Classification | 범주 예측 |
| Regression | 숫자 예측 |
| Clustering | 비슷한 것끼리 그룹화 |
| K-means | 대표적인 군집화 방법 |
| PCA | 차원 축소 |
| Train | 공부 |
| Validation | 모의고사 / 모델 선택 |
| Test | 최종시험 |
| Overfitting | 외운 문제만 잘 푸는 상태 |
| Generalization | 처음 보는 문제도 잘 푸는 능력 |

## 10. 오늘 이해한 핵심

1. 숫자를 맞히면 회귀, 종류를 맞히면 분류다.
2. 지도학습은 정답이 있고, 비지도학습은 정답이 없다.
3. K-means는 비슷한 데이터끼리 묶고, PCA는 많은 변수를 중요한 방향으로 줄인다.
4. 선형회귀의 `w`는 기울기, `b`는 절편 역할을 한다.
5. 머신러닝 학습은 예측 → Loss 계산 → 파라미터 수정의 반복이다.
6. 데이터 분리는 단순히 행을 랜덤하게 나누는 문제가 아니다. 같은 고객처럼 서로 연관된 데이터가 Train과 Validation에 동시에 들어가면 데이터 누수가 생길 수 있다.
