# Today I Learned (TIL)

매일 학습한 내용을 짧고 명확하게 기록합니다.

## 기록 원칙
- 단순 개념 복사보다 **오늘 이해한 것** 중심으로 작성
- 코드가 있다면 실행 흐름과 헷갈렸던 지점을 함께 기록
- 하루 1개 파일을 기본으로 사용
- 파일명: `YYYY/MM/YYYY-MM-DD.md`

## 주요 학습 영역
- Python
- Django / Backend
- SQL / Database
- AI / LLM / Agent
- Git / GitHub
- 프로젝트 문제 해결

## 기록 구조
1. 오늘 배운 것
2. 핵심 개념
3. 직접 이해한 실행 흐름
4. 실수 또는 헷갈린 점
5. 다음에 확인할 것
