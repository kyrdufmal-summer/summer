# Today I Learned (TIL)

매일 학습한 내용을 **날짜별 요약 + 주제별 상세 문서** 방식으로 기록합니다.

## 운영 원칙

- 날짜별 TIL에는 하루의 학습 흐름과 핵심 이해를 짧게 정리한다.
- 내용이 길어지거나 다시 찾아볼 가치가 있는 주제는 별도 주제 문서로 분리한다.
- 날짜별 TIL에서 주제별 상세 문서로 링크한다.
- 단순 개념 복사보다 **직접 이해한 것, 시행착오, 문제 해결 과정**을 중심으로 작성한다.
- 명령어는 외우는 대상이 아니라 **왜 실행했는지와 어떤 상태를 확인하려는지** 함께 기록한다.
- 비밀번호, 운영 DB 주소, API Key, Secret, 실제 개인정보 등 민감 정보는 커밋하지 않는다.

## 날짜별 TIL

경로:

```text
TIL/YYYY/MM/YYYY-MM-DD.md
```

기본 구성:

1. 오늘 한 일 요약
2. 주요 학습 주제
3. 직접 이해한 실행 흐름
4. 시행착오 / 헷갈렸던 점
5. 사용한 명령어와 목적
6. 주제별 상세 문서 링크
7. 다음에 확인할 것

## 주제별 상세 문서

내용이 길어지는 기술 주제는 별도 폴더에 누적한다.

예:

```text
TIL/DB/
TIL/Django/
TIL/Python/
TIL/AI/
TIL/Git/
TIL/선형대수/
```

주제별 문서에는 가능한 한 다음 내용을 포함한다.

1. 정의
2. 왜 필요한지
3. 전체 메커니즘
4. 실행 흐름
5. 명령어 / 코드의 역할
6. 실수 또는 장애 원인
7. 실무에서의 사용 방식
8. 보안 및 주의사항

## 주요 학습 영역

- Python
- Django / Backend
- SQL / Database
- AI / LLM / Agent
- Git / GitHub
- 선형대수 / 머신러닝
- 프로젝트 문제 해결

## 목표

단순히 커밋 수를 늘리는 학습 일지가 아니라, 시간이 지나도 다시 읽으면 **무엇을 정의했고, 어떤 문제를 만났고, 어떤 근거로 해결했는지** 이해할 수 있는 기술 포트폴리오를 만든다.
