# 2026-08-25 TIL

## 오늘 배운 것
- TIL을 GitHub 포트폴리오 자산으로 운영하기 위한 기본 구조를 만들었다.
- 기존 포트폴리오 저장소를 유지하면서 `TIL/` 디렉터리 아래에 날짜별 학습 기록을 누적하는 방식을 사용한다.

## 핵심 개념
- **TIL (Today I Learned)**: 하루 동안 배운 내용, 시행착오, 이해한 원리를 짧게 기록하는 개발 학습 로그.
- 단순히 커밋 수를 늘리는 것보다, 시간이 지나도 다시 이해할 수 있는 기록이 중요하다.
- 채용 관점에서는 `무엇을 배웠는가`보다 `어떤 문제를 어떻게 이해하고 해결했는가`가 더 가치 있다.

## 운영 규칙
- 파일명: `YYYY/MM/YYYY-MM-DD.md`
- 기본 구성:
  1. 오늘 배운 것
  2. 핵심 개념
  3. 직접 이해한 실행 흐름
  4. 실수 또는 헷갈린 점
  5. 다음에 확인할 것

## 포트폴리오 관점
앞으로 Python, SQL, Django, Git/GitHub, AI/LLM/Agent, 프로젝트 트러블슈팅 등을 같은 저장소에 누적한다.

목표는 단순한 학습 일지가 아니라, 시간이 지나면서 **문제를 구조화하고 해결하는 과정이 보이는 기술 포트폴리오**를 만드는 것이다.
